# 候选降雨输入

19 个输入：单/双/三峰 × 20/40/60/80/120/160 mm，再加源 bpswmm_2413 小时序列（35 mm）。全部尚未模拟，不是已冻结的正式论文矩阵。

格式 timestamp,value；value 为 mm/h，区间起点记时，末尾零记录结束降雨。源站 RainGage，激活序列 bpswmm_2413；模型运行时由现有通用工具替换该序列。

合成雨为 2020-07-15 00:00–04:00，当前政策给出 24 h 模拟窗。原始小时雨结束于 2020-07-16 01:00，按同一 20 h 尾段政策总窗 45 h，区别于原 INP 的 26 h。源实测出处与重现期均未核实。

逐事件哈希、累计量、源曲线和用途见 manifest.json；更改后须重建对应运行请求，不复用过期哈希。

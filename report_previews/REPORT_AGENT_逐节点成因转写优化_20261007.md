# 第五章逐节点分析：提示词与案例优化（2026年10月7日）

## 本轮目标

将总体成因段落已采用的成品报告写法延伸至全部逐节点分析：直接解释来水与排水怎样形成冒溢，保留原诊断中的作用关系，去掉内部判断状态、机制清单和重复总结。

“以下结合各节点的发生过程与成因判断，说明……”并非明确的语法错误，但表达绕，主要是在解释写作安排。总体成因提示词改用“各节点的来水组成和排水条件有所不同，下面分别分析”，也允许省略过渡句。此前模型生成的总体成因试写文件保留原样。

## 已接入正式生成流程

- [逐节点转写提示词](../workflow_agents/reporting/prompts/event_rewrite_v1.md)：区分过程与成因，直接展开具体作用，禁止机制枚举式开头及重复收尾；补充来水来源重复、调蓄句子缺少作用对象、起溢与峰值水位描述的自审要求。
- [P6成对教学案例](../workflow_agents/reporting/prompts/event_example_v1.json)：示范多路来水和高峰期输水受限；去掉原案例中再次总结“共同解释此次冒溢”的结尾。
- [P43成对教学案例](../workflow_agents/reporting/prompts/event_example_lateral_v1.json)：示范只有本地侧向来水、出流短时下降后恢复的事件。与P6对照，避免把所有节点套成同一种过程。
- [P44成对教学案例](../workflow_agents/reporting/prompts/event_example_outflow_v1.json)：示范起溢时入流已经回落、出口仍未满足排水需要的解释；成因段不必罗列全部来水份额。
- [总体成因提示词](../workflow_agents/reporting/prompts/causes_overview_v1.md)：修改逐节点分析的衔接句。
- [模型输入组装](../workflow_agents/reporting/narrative.py)：将P43、P44案例作为`additional_teaching_examples`传入实际调用，保留原来的P6案例字段与事实、机制检查。
- [生成流程](../workflow_agents/reporting/pipeline.py)：版本更新为`report_agent_v1.4_event_prose`，提示词与案例均参与生成文件哈希和缓存检查。
- [逐节点试写程序](../scripts/probe_report_events.py)：调用项目当前配置模型，单独试写全部事件，保留原始响应、事实标记输出、展开后的正文及输入来源哈希。

当前模拟与诊断材料来自`20261005_104641`运行、`6b2fbc831220478db26b1006c694e884`任务的r2。使用已有报告目录`20261007_155723_f52d5122`保存的材料，未重新模拟或重新诊断。

- [第一轮正文](./report_agent_examples/event_prose_probe_20261007_v1/逐节点分析_试写.md)：已去掉候选状态补丁，但几乎每个成因段都以“由……共同造成”开头，再展开同一组原因，仍有模板感。
- [第二轮正文](./report_agent_examples/event_prose_probe_20261007_v2/逐节点分析_试写.md)：去掉上述机制清单式起句；下游影响保持一句具体解释。仍存在“全部本地来水”紧接100%份额、来源名单重复和“未能明显缓冲”缺少对象的问题。
- [第三轮正文](./report_agent_examples/event_prose_probe_20261007_v3/逐节点分析_试写.md)：减少来源重复，但多数成因段改成以份额统计开头，阅读顺序又退回数据优先。该轮不是最终推荐的表达。

第四轮实际调用一次通过程序检查，覆盖全部7个事件。人工审读：P43不再重复“全部来水”与100%份额；P44从汇流和出口排水需要展开，保留起溢时入流回落这一特点；P42的下游段正确写成此前冒溢已结束而水位仍接近井口。全部下游影响均为具体的一句解释，没有追加内部状态说明。其他多路汇流节点的成因句式仍较相近，过程段也仍有较密的采样数值，后续可继续打磨，不能将本次检查通过当作整份报告语言已经完善。

第四轮输出与人工审读结论另存在该目录的`editorial_review.json`。原文没有手工修订。此次教学案例与当前模拟属于同一运行，其他运行上的表达泛化效果尚需独立试验；该记录属于开发说明，不进入成品报告。

这些正文均为项目配置模型的实际输出，没有手工替换为撰写案例。每轮覆盖P6、P7、P43、P44、P46、P42、P48全部7个节点。示例中的教学标记与当前模拟事实分别保存，禁止案例数字进入本次报告。

试写只替换内存中的逐节点正文，用已通过检查的总体成因试写作为其他章节的检查基线；`combined_narrative.json`是试验记录，并未发布为整份新报告。原有HTML与任务状态保持不变。

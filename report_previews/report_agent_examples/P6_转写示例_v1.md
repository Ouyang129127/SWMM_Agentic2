## 三、可用于提示词的逐节点写作要求

以下为本例拟议的提示词片段。迁移到其他节点时保留表达规则，替换全部案例材料。

> 根据当前节点的事件事实、过程数据与诊断判断，写面向人的逐节点分析。表达原诊断已经形成的解释，保留各因素的作用关系和判断力度。
>
> 输出包含一个概括节点特点的标题、“发生过程”和“成因判断”。通常各用一至两个自然段；根据本节点内容调整，不为满足段数补写内容。
>
> “发生过程”回答何时开始、如何增强、何时达到峰值、如何停止。选取能说明变化的数值，围绕变化组织句子。不要逐个采样时刻转抄全部指标，不把正文写成数据表。
>
> “成因判断”回答来水怎样形成排水压力、排水受到什么限制、水位为何达到冒溢位置，以及这些因素如何共同作用。若当前诊断支持调蓄影响，解释其在此过程中的作用。候选影响自然使用“可能”等措辞，与有支持的主要解释区分。
>
> 学习示例中的组织方式，使用当前输入的节点、管段、数值和判断。其他节点不自动继承本例的来水组成、出流平台、调蓄判断或下游顶托。
>
> 正文保持专业、自然、简洁。使用具体节点、管段名称和变化动词。避免反复使用“……方面”“得到支持”“候选机制”等评估式语言。
>
> 正文不展示证据编号、机制编号、内部字段、保存步长提醒或证据缺口清单。判断强度通过正常措辞表达，内部来源和核查信息单独保存。
>
> 所有数值对应明确的对象、指标和时刻或事件区间。来源份额表达为直接来水的组成，不改称致涝贡献率。将高峰时实测出流与入流比较，不把该出流数值写成管段永久不变的最大能力。
>
> 依据已有诊断解释变化，不自行计算未提供的关键指标、不做贡献率分解、不承诺改造效益、不新增致涝原因。节点冒溢分析与地表内涝统计分别表达，不将节点冒溢直接等同于地表达到15厘米。

## 四、目标正文：供讨论确认

### P6：多路来水叠加，G6高峰期输水受限

#### 发生过程

P6在01:37开始冒溢，持续约5分钟，累计冒溢量约16.28立方米。冒溢流量随后增强，于01:40达到约79.4升/秒的峰值。

高峰时，P6总入流约为295.0升/秒，而G6同期出流约为215.6升/秒。01:38—01:40，来水继续增加，G6出流基本保持稳定，节点水深维持在1.0米，冒溢随之增强。到01:42，节点水深回落至约0.88米，冒溢结束。

#### 成因判断

P6接收G4、G5和本地侧向来水，三者分别约占冒溢期间直接进入节点水量的64%、20%和16%。多路来水在同一时段汇入，增加了节点的排水压力；G6已经满流，高峰附近的出流未能跟上来水增加，节点水位升至井口并发生冒溢。相关节点和管段的可用调蓄有限，也未能明显缓冲这一来水高峰。因此，多路来水叠加、G6的局部输水约束与水位达到井口，共同解释了此次冒溢。

下游P7同一时段也发生冒溢，其高水位可能对G6产生顶托，使P6向下游排水更加困难。这一影响可能与局部输水约束共同作用。

## 五、这份转写做了什么

| 输入材料 | 转写处理 | 表达目的 |
|---|---|---|
| 七个时刻的过程数据 | 选择起溢、峰值及结束，概括高峰变化 | 讲清事件发生和消退，不逐行复述 |
| 来源组成、同刻流量 | 用来源份额交代来水结构，用高峰入流与出流对比说明压力 | 将不同时间口径的数字放在对应语境 |
| 多个有支持的机制 | 组织成“汇入增加压力 → 排水受限 → 水位达到井口 → 冒溢”的解释关系 | 保留综合推断及共同作用 |
| 已支持的调蓄判断 | 说明未能明显缓冲来水高峰 | 保留新r2补证形成的诊断内容 |
| 候选下游影响 | 使用“可能”说明进一步影响排水 | 保留候选判断力度，正常面向读者表达 |
| 内部边界和证据记录 | 留在内部材料 | 正文保持展示产品的阅读体验 |

这些解释关系来自原诊断的作用关系，不是让Report Agent仅凭几个机制状态重新推断因果。

## 六、检查标准

### A. 事实与诊断忠实性

- 起止、峰值、持续时间和冒溢量与本事件一致；保留值与展示舍入关系可核对。
- 295.0升/秒对应01:40的P6总入流；215.6升/秒对应G6同期出流；79.4升/秒对应P6冒溢峰值。
- 64%、20%、16%对应事件期间直接来水的水量组成，不能改为峰值流量比例或成因贡献。
- 调蓄段落来自当前r2支持的判断；遇到其他诊断版本应重新选择内容。
- 下游P7影响保持“可能”，不能写成已确定主因，也不能写成P7地表冒溢水回流P6。
- 215.6升/秒是本次高峰附近的保存出流，不能写成G6永久固定的最大过流能力。
- 没有新增设施、成因、贡献率、地表流向或改造结论。

### B. 是否完成理解与转写

- 过程段落围绕变化组织，不逐时刻抄全量指标。
- 成因段落包含作用关系，不仅列出“多源来水、满流、井口、调蓄有限”。
- 读者能够理解本节点来水压力、排水限制及冒溢位置之间的关系。
- 调蓄和下游影响有清楚的语义位置；主要解释与候选影响可以分辨。
- 各节点可以呈现自己的特点，不用替换节点名就能批量复制本例。

### C. 展示语言

- 无机器字段、证据编号和内部核查提示。
- 使用具体管段名，例如“G6出流”，避免笼统的“直接相连管段排出量”。
- 已交代日期的同日案例使用时分；跨日事件通过明确日期消除歧义。
- 数值精度适合阅读；正文没有为完整复述数据而连续堆砌数字。
- 与配图互补；正常说明已有判断，不加入论文式方法边界段落。

### D. 常见不合格表达及原因

| 表达 | 问题 |
|---|---|
| 每个时刻各写一段入流、出流、水深、水头 | 复述数据，缺少变化解释 |
| “由多源来水、满流、井口共同作用；调蓄有限”后即结束 | 只有机制名称，未解释如何共同作用 |
| “G4的致涝贡献为64%” | 将直接来水组成升级为致涝贡献 |
| “G6的最大排水能力就是215.6升/秒” | 将本次保存出流升级为固定能力 |
| “P7顶托导致P6冒溢”作为确定结论 | 升级候选判断 |
| “P7冒溢水回流P6” | 新增未经诊断支持的地表回流路径 |
| “未被证实、无反事实验证、保存步长影响”逐项加入正文 | 把内部核查与方法说明搬进展示产品 |

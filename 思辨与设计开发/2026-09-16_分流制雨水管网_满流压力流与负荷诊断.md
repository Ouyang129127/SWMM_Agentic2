# 分流制雨水管网：满流、压力流与负荷诊断的思辨记录

日期：2026-09-16  
用途：论文概念梳理与 Diagnosis Agent 设计依据。本文记录工程认识和拟议诊断逻辑，不代表代码已经实现，也不构成具体项目的设计合规结论。  
范围：分流制中的雨水管网；不将雨水管的满流计算原则直接套用到重力流污水管。

## 1. 问题从哪里来

原先十大诊断问题包含“哪些管段长期满流”“流量是否明显超过满流能力”。如果直接把满流视为异常，就会与雨水管道按满流计算的设计原则发生冲突。

需要分开回答三个问题：

1. 管道当前是什么水力状态？
2. 在本场降雨、外水位和运行条件下，这个状态是否符合性能目标？
3. 如果出现节点溢流和地面积水，哪些因素促成了这些后果？

满流是状态证据，不能直接充当故障判据或根本原因。

## 2. “按满流计算”不等于追求所有降雨下都满流

GB 50014—2021 第5.2.4条区分了重力流污水管的非满流计算与雨水、合流管道的满流计算。第5.1.8条条文说明将雨水管渠设计重现期下的重力流、满管流计算，与内涝防治设计重现期下的压力流校核联系起来。[1][2]

这意味着选定设计流量、管径、坡度、糙率和边界条件后，以满管输水作为设计计算参照；不要求所有管段在某场雨中同时满流，更不要求任何降雨强度下都满流。

实际选用管径、上下游衔接、汇流时差和边界水位均会影响运行状态。小雨下通常可能非满流，但不能仅凭“小雨时满流”断定设计错误，还需排查外水顶托、初始蓄水、异常入流和控制设施。

雨水管渠设计标准和内涝防治标准是不同层面的性能要求。设计重现期内是否满足要求，需要结合项目适用标准、设计工况和服务目标评价；无溢流也不能单独证明整个工程合规。

对于实测降雨，重现期与统计历时有关，不能只用总雨量或单个瞬时峰值赋予一个无条件的“事件重现期”。

## 3. 满流与压力流的严格关系

需要修正讨论中的简化表达：“满流、压力流、溢流”不是三个完全互斥的流态。

- 满流：描述断面是否充满。
- 压力流：描述封闭管道内的压力状态；常规正压满管工况下，测压管水头高于管顶。
- 溢流：描述水是否经节点离开管网，是节点边界行为和排水后果。

压力流往往同时是满流。重力也能够驱动压力流，因此“靠重力输水”和“存在正压”并不矛盾。设计中的满管重力流计算是特定水力条件下的计算方式，不能把实际满管运行理解为整个管内均无压力。

| 观察对象 | 可用判据或证据 | 不能直接推出的结论 |
|---|---|---|
| 非满流断面 | 有自由水面，水深低于断面高度 | 整条管或整个系统没有顶托 |
| 断面满流 | 水深达到断面高度，或端部达到充满条件 | 必然超负荷、必然溢流 |
| 正压满管状态 | 局部测压管水头高于管顶，并结合充满状态 | 压力一定来自下游外水顶托 |
| 节点溢流 | SWMM节点Flooding流量及累计体积，结合节点设置 | 邻近任意满流管就是主因 |

同一根管可以一端充满、另一端未充满，流态也随时间变化。端点证据不等于对整条管内状态的完整观测。

“顶托”还涉及下游条件对上游水位的影响，是机制判断。仅发现正压不足以证明顶托；自由水面流也可能存在回水影响。

## 4. 用水位与高程判断压力和溢流风险

对于普通圆管端部：

```text
管顶高程 = 端部管底高程 + 内径
节点水头 H = 节点底高程 + 节点水深
端部压力水头指标 ΔHc = H - 管顶高程
地面余量 F = 地面或井口高程 - H
```

HGL指测压管水头线；在检查井自由水面处通常可用节点水位表征。它不等于包含流速水头的能量线。

计算管顶高程必须考虑管道端部偏移量及其采用高程还是相对高度的输入约定，不能统一用节点底高程加管径代替。

ΔHc显著大于零可支持该端部受压判断；接近零属于充满过渡区域。应设置与输出精度和工程尺度相适应的容差。节点水头作为管端判据是实用近似，还应考虑局部损失与模型表达。

F小于零表示水头超过所采用的地面或井口高程，但SWMM是否报告Flooding还受最大水深、允许超压水深、节点类型及地表蓄水设置影响。模型水位可能被约束在溢流边界附近，同时已有正的溢流流量，因此不能只用“H严格大于地面”检测事件。[3]

诊断应同时保存：模型溢流量、模型溢流阈值、实际地面高程及三者的一致性。

## 5. 如何解释 Q/Qfull

常规正坡条件下，满管均匀流参照可由曼宁公式计算：

```text
Qfull = (1/n) × Afull × Rfull^(2/3) × S0^(1/2)
rq = |Q| / Qfull
```

其中S0是用于该参照计算的管底坡度；一般曼宁关系使用摩阻坡降，均匀流条件下才与管底坡度相等。

Qfull不是所有非恒定工况下不可突破的绝对输水上限。动力波条件下，水头差、下游水位与蓄泄过程会改变流量。圆管近满的自由水面均匀流，也可能出现流量高于满管均匀流参照的情况。[4]

因此：

- rq大于1：实际流量超过该满管均匀流参照，不能单独证明压力流、模型错误或系统失效。
- rq小于1：不能证明无风险；管道可能因下游高水位而充满，却仅有较小流量。
- rq不是线性的“剩余能力百分比”；1-rq不能直接解释为可再接纳的径流比例。

对于零坡、倒坡、泵、堰、孔口和特殊断面，应使用适合该对象的计算口径。不能为了得到比值而随意取坡度绝对值。必须记录Qfull来自SWMM属性还是自行计算，并注明假设。

## 6. 管网负荷应是一组指标

| 维度 | 建议保存的证据 | 回答的问题 |
|---|---|---|
| 工况背景 | 降雨过程与历时、设计标准、外水位、初始条件、设施控制 | 本次评价采用什么条件与目标？ |
| 输水状态 | 流量及方向、rq、水深比、充满时段 | 输水接近什么参照水平？ |
| 压力状态 | 两端水头、管顶高程、压力水头及时段 | 哪里受压，持续多久？ |
| 节点后果 | 地面余量、Flooding峰值/体积/持续时间 | 是否失去管内排水控制？ |
| 空间联系 | 连续受压路径、上下游水位和流量时序 | 是局部现象还是系统性约束？ |
| 地表后果 | CA2D热点编号、位置、面积、深度、起止时间 | 排水后果形成多大淹没影响？ |

如采用“接近满流”的阈值，应标明它是研究筛查阈值，而非通用规范判据。持续时间也必须注明由求解步统计还是报告时步估算；低频输出可能遗漏短时压力和溢流峰值。

若汇总全网满流比例，应明确按管段数量还是管长加权，并同时展示关键通道和热点附近的状态。不同管段并非具有相同的重要性。

## 7. 对 Diagnosis Agent 的直接影响

原问题“哪些管段长期满流”应展开为：

1. 哪些管段、哪些端部何时充满或受压？
2. 当时流量、水位差和节点地面余量如何？
3. 这些状态是否与节点溢流存在时间和水力联系？
4. 结合本场工况与性能目标，属于可解释运行状态，还是需要继续追踪的风险信号？
5. 有哪些竞争性解释，下一步读取什么数据或进行什么试验可以区分？

仅靠满流持续时间，不得输出“瓶颈已确认”。应同时检查上游来流叠加、局部输水约束、下游水位、泵站控制以及模型高程与数值表现。

建议采用以下证据层次：

- 事实：管段端部受压、节点发生溢流等可复算结果。
- 候选机制：下游顶托、上游集中入流、局部能力受限等解释。
- 验证结论：通过针对性的对比模拟或独立观测进一步支持的判断。
- 未解决问题：现有输出不足以区分的替代解释。

“出口水位先升、上游随后受压”可以支持下游影响假说，但共同降雨驱动也可能造成相关性。要判断主因/次因，应明确评价指标，在可解释的对照条件下比较改变边界、来流或设施后的溢流和淹没变化；多个机制可能相互作用，不能随意将影响拆成相加百分比。

LLM可负责提出竞争性假说、选择追踪方向、调用证据工具并根据结果修正解释。公式计算、事件提取与证据定位应由确定性工具完成。LLM不能仅凭“满流64分钟”就认定下游顶托是主因。

## 8. 与当前项目的衔接

本次整理未重新审计或修改代码。按前期讨论，已有充满度、流量、持续时间等基础指标；后续需逐项核查节点水头、两端管顶高程、井口高程、超压设置及SWMM报告统计是否已被完整提取。

实现时应区分SWMM的端部充满统计、超过满管均匀流的统计及容量受限统计；它们不是同一指标。[3]

本项目保持既定分析链：

```text
降雨及汇水 → SWMM管网水力过程 → 节点溢流 → CA2D地表淹没
                                ↑
           根据管段、节点、边界与设施的证据追踪机制
```

最终报告既应呈现热点的淹没后果，也应解释源节点为何溢流。满流、受压和溢流之间的时空联系构成诊断证据，不能由一个充满度阈值替代。

## 9. 对前一轮口头解释的校正

1. “满流不等于压力流”应理解为两者描述不同属性；不能理解为互斥。
2. 重力驱动不排斥正压；不能宣称满管重力输水时整条管的HGL都不得超过管顶。
3. Q/Qfull大于1不必然证明受压，小于1也不意味着安全。
4. 水头高于地面是风险信号，节点溢流事件还应直接读取模型Flooding，并检查边界设置。
5. 压力流不自动证明下游顶托；发生溢流也不能直接定位主因。
6. 前文L-18、L-32、N-23等案例数字为说明性示例，未经项目结果验证，不得作为论文实证。

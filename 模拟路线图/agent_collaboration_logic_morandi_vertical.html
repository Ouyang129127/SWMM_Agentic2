SWMM-CA2D Agentic 洪涝灾害成因分析纵向流程图

纵向版突出主工作链路：用户任务经 StatefulOrchestrator 进入状态机，依次完成情景准备、耦合模拟、证据构建、灾害诊断、证据核查与解释报告；右侧保留关键数据产物，底部承接论文评价模块。

输入/输出 编排控制 状态判断 工作流 Agent 证据与核查产物 论文评价模块 
flowchart TD
    START([用户 / 专家任务
降雨情景、模型检查、内涝诊断、解释需求])
    ORCH{{StatefulOrchestrator
任务理解、阶段调度、状态合法性控制}}
    STATE{workflow_state.json
当前允许进入哪个阶段?}

    START --> ORCH --> STATE

    STATE --> SCA[[ScenarioAgent
模型要素检查
降雨事件识别
情景请求生成]]
    SCA --> REQ[/scenario_request.json
模型-降雨-情景-运行编号/]
    REQ --> D1{SCENARIO_READY?}

    D1 -->|是| SIM[[SimulationAgent
固定 SWMM -> CA2D
耦合模拟管线]]
    D1 -.否：补齐模型、降雨或情景.-> SCA

    SIM --> MODEL[(模型与情景库
SWMM 管网 / CA2D 元胞
events / scenarios)]
    MODEL --> SIM
    SIM --> RAW[/标准运行输出
summary.json, run.yaml
nodes.tsv, links.tsv, surface_depth.tsv/]
    RAW --> D2{RUN_READY?}

    D2 -->|是| EBA[[EvidenceBuilderAgent
结构化证据构建]]
    D2 -.否：检查模拟管线与输出.-> SIM

    EBA --> EVID[(evidence_table.csv
对象、指标、数值、时段、来源文件)]
    EBA --> ESUM[/evidence_summary.json
证据数量、指标类型、来源文件/]
    EVID --> D3{EVIDENCE_READY?}

    D3 -->|是| DIA[[DiagnosisAgent
热点识别
风险排序
可能成因判断]]
    D3 -.否：补齐标准证据表.-> EBA

    DIA --> CLAIMS[/diagnosis_claims.json
claim_id, severity, possible_cause, evidence_ids/]
    DIA --> RISK[(risk_ranking.csv
热点网格、溢流节点、高负荷管段)]
    CLAIMS --> D4{DIAGNOSIS_READY?}

    D4 -->|是| VER[[VerificationAgent
证据引用核查
无证据结论拦截]]
    D4 -.否：重新生成可证据绑定 claim.-> DIA
    EVID --> VER

    VER --> VREP[/verification_report.json
supported / partially_supported / unsupported/]
    VER --> RATE[(unsupported_rate.txt
无证据结论比例)]
    VREP --> D5{VERIFIED_READY?}

    D5 -->|是| REP[[ReportAgent
证据约束报告
单点成因解释]]
    D5 -.否：修正证据引用或标记 unsupported.-> VER

    EVID --> REP
    RISK --> REP
    RATE --> REP
    REP --> OUT([Evidence-grounded Report
结论-证据-对象-时段-来源文件可追溯])

    OUT --> BENCH{{Benchmark / 论文评价模块
task success, F1, Spearman, unsupported rate}}
    VREP --> BENCH
    RATE --> BENCH
    BENCH --> PAPER([论文 Results 与图表
架构图、证据链、诊断效果、消融对比])

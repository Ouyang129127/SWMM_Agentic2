SWMM-CA2D Agentic 洪涝灾害成因分析工作链路图

新版图按照当前 SWMM-Agentic2 的真实 Agent 边界组织：以 StatefulOrchestrator 控制状态转移，以 Scenario、Simulation、EvidenceBuilder、Diagnosis、Verification 和 Report 构成从情景准备到证据追溯的闭环；Benchmark 作为论文评价模块单独承接已核查成果。

flowchart TD
    U["用户 / 专家任务
降雨情景、模型检查、内涝诊断、解释需求"] --> ORCH["StatefulOrchestrator
任务理解、阶段调度、状态合法性控制"]
    ORCH --> STATE["workflow_state.json
START / SCENARIO_READY / RUN_READY / EVIDENCE_READY / DIAGNOSIS_READY / VERIFIED_READY"]

    STATE --> SCA["ScenarioAgent
模型要素检查、降雨事件识别、情景请求生成"]
    SCA --> REQ["scenario_request.json
model_name, event_name, scenario_name, run_id"]

    REQ --> SIM["SimulationAgent
固定 SWMM -> CA2D 耦合模拟管线"]
    SIM --> SWMM["SWMM 一维排水管网
节点、管段、子汇水区、溢流过程"]
    SIM --> CA2D["CA2D 二维地表元胞
积水深度、持续时间、空间热点"]

    SWMM --> RAW1["SWMM 标准输出
node_flooding.tsv, nodes.tsv, links.tsv"]
    CA2D --> RAW2["CA2D 标准输出
surface_depth.tsv, max/final depth maps"]
    SIM --> RUN["RUN_READY
summary.json, run.yaml, 标准运行目录"]

    RUN --> EBA["EvidenceBuilderAgent
结构化证据构建"]
    RAW1 --> EBA
    RAW2 --> EBA
    EBA --> EVID["evidence_table.csv
evidence_id, object_id, metric, value, time, source_file"]
    EBA --> ESUM["evidence_summary.json
证据数量、指标类型、来源文件"]

    EVID --> DIA["DiagnosisAgent
热点识别、风险排序、可能成因判断"]
    DIA --> CLAIMS["diagnosis_claims.json
claim_id, severity, possible_cause, evidence_ids"]
    DIA --> RISK["risk_ranking.csv
内涝热点、溢流节点、高负荷管段排序"]

    CLAIMS --> VER["VerificationAgent
证据引用核查、无证据结论拦截"]
    EVID --> VER
    VER --> VREP["verification_report.json
supported / partially_supported / unsupported"]
    VER --> RATE["unsupported_rate.txt
无证据结论比例"]

    VREP --> REP["ReportAgent
证据约束解释报告、单点成因分析"]
    RATE --> REP
    EVID --> REP
    RISK --> REP
    REP --> OUT["Evidence-grounded Report
结论-证据-对象-时段-来源文件可追溯"]

    VREP --> BENCH["Benchmark / 论文评价模块
task success, F1, Spearman, unsupported rate"]
    RATE --> BENCH
    OUT --> PAPER["论文 Results 与图表
Agent 架构、证据链、诊断效果、消融对比"]
    BENCH --> PAPER

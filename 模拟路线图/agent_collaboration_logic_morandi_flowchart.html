SWMM-CA2D Agentic 洪涝灾害成因分析流程图

该版本用不同流程图形状表达不同语义：圆角表示开始/结束，菱形表示状态判断，子程序形状表示 Agent 阶段，数据库/文档形状表示模型、证据与报告产物。

输入/输出 编排控制 状态判断 工作流 Agent 证据与核查产物 论文评价模块 
flowchart LR
    START([用户 / 专家任务
降雨情景、模型检查、诊断解释]) --> ORCH{{StatefulOrchestrator
任务理解与流程调度}}
    ORCH --> STAGE{当前 workflow_state
允许进入哪个阶段?}

    STAGE -->|START| SCA[[ScenarioAgent
模型要素检查
降雨事件识别
情景请求生成]]
    SCA --> REQ[/scenario_request.json
模型-降雨-情景-运行编号/]
    REQ --> READY1{SCENARIO_READY?}

    READY1 -->|是| SIM[[SimulationAgent
固定 SWMM -> CA2D
耦合模拟管线]]
    SIM --> MDB[(模型与情景库
SWMM 管网 / CA2D 元胞
events / scenarios)]
    MDB --> SIM
    SIM --> RAW[/标准运行输出
summary.json, run.yaml
nodes.tsv, links.tsv
surface_depth.tsv/]
    RAW --> READY2{RUN_READY?}

    READY2 -->|是| EBA[[EvidenceBuilderAgent
结构化证据构建]]
    EBA --> EVID[(evidence_table.csv
对象、指标、数值、时段、来源文件)]
    EBA --> ESUM[/evidence_summary.json
证据数量、指标类型、来源文件/]
    EVID --> READY3{EVIDENCE_READY?}

    READY3 -->|是| DIA[[DiagnosisAgent
热点识别
风险排序
可能成因判断]]
    DIA --> CLAIMS[/diagnosis_claims.json
claim_id, severity, possible_cause, evidence_ids/]
    DIA --> RISK[(risk_ranking.csv
热点网格、溢流节点、高负荷管段)]
    CLAIMS --> READY4{DIAGNOSIS_READY?}

    READY4 -->|是| VER[[VerificationAgent
证据引用核查
无证据结论拦截]]
    EVID --> VER
    VER --> VREP[/verification_report.json
supported / partially_supported / unsupported/]
    VER --> RATE[(unsupported_rate.txt
无证据结论比例)]
    VREP --> READY5{VERIFIED_READY?}

    READY5 -->|是| REP[[ReportAgent
证据约束报告
单点成因解释]]
    EVID --> REP
    RISK --> REP
    RATE --> REP
    REP --> OUT([Evidence-grounded Report
结论-证据-对象-时段-来源文件可追溯])

    OUT --> BENCH{{Benchmark / 论文评价模块
task success, F1, Spearman, unsupported rate}}
    VREP --> BENCH
    RATE --> BENCH
    BENCH --> PAPER([论文 Results 与图表
架构图、证据链、诊断效果、消融对比])

    READY1 -->|否| FIX1[[返回 ScenarioAgent
补齐模型、降雨或情景要素]]
    READY2 -->|否| FIX2[[返回 SimulationAgent
检查模拟管线与运行输出]]
    READY3 -->|否| FIX3[[返回 EvidenceBuilderAgent
补齐标准证据表]]
    READY4 -->|否| FIX4[[返回 DiagnosisAgent
重新生成可证据绑定 claim]]
    READY5 -->|否| FIX5[[返回 VerificationAgent
修正证据引用或标记 unsupported]]

    FIX1 --> SCA
    FIX2 --> SIM
    FIX3 --> EBA
    FIX4 --> DIA
    FIX5 --> VER
